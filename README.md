# DCFilter

디시인사이드 데스크톱 갤러리용 비공식 Manifest V3 확장 프로그램입니다. 이미지 보호, 댓글·게시글 필터, 화면 정리, 읽음 표시와 작성자 활동 분석을 제공합니다.

DCFilter는 디시인사이드가 제작하거나 운영하는 제품이 아니며, 디시인사이드와 제휴·후원 관계가 없습니다. Chrome과 Edge에서 압축을 푼 확장 프로그램으로 설치할 수 있습니다.

[최신 배포 ZIP 다운로드](https://github.com/fueenai/DCFilter/releases)

## 주요 기능

- 봇 의심 댓글 접기: 등록 예시와 거의 같은 문장, 여러 정형적 표현과 반복 패턴이 겹치는 댓글을 로컬 규칙으로 접고 이유·원문 보기 제공
- 로컬 AI 혐오·잔혹·성적 이미지 사전 차단(실험적): 본문·댓글 이미지·목록 썸네일·호버 미리보기를 검사 전부터 가리고, 검사 후 유해 의심 이미지를 차단
- 게시글 목록 자동 갱신(현재 보이는 목록 상단에서만, 최소 3초; 입력·미리보기·분석 중 정지)
- 게시글 새 탭 열기, 전체 작성 시간 표시
- 실제로 연 글의 읽음 표시와 지난 열람 대비 댓글 증가분(`+5` 등) 표시
- 뒤로가기로 목록에 복귀할 때 페이지·검색 조건별 스크롤 위치 복원과 읽은 행 강조
- 닉네임 ID 표시(고정닉·반고정닉 포함)와 J/K 키보드 목록 탐색
- 다크 모드, 글꼴/크기/강조색(기본값 디시 남색 `#3b4890` — 링크·버튼·상단 메뉴·강조 틴트가 모두 이 한 색에서 파생), 컴팩트 목록
- 라이트·다크·시간대 자동·시스템 테마와 헤더/목록/본문/댓글 통합 팔레트
- 분류별 설정 화면과 검색, 미저장 변경 되돌리기, Ctrl+S 저장
- 설정·키워드·사용자 차단 목록 JSON 백업과 미리 확인 후 불러오기
- 실시간 베스트, 디시미디어·디시이슈, 추천 개념글 박스, 목록 이슈 행 개별 숨김
- 상단 신규 갤러리·통계·로터리 슬롯 숨김(표시 시 GNB 아래 전용 스트립으로 정돈)
- 최근 방문 바를 가로 탐색 레일로 정돈하고 전체 목록을 내용 기반 2열 패널로 표시
- 파란 그라데이션 `dF` 전용 확장 아이콘(16/48/128px, 투명 모서리)
- 추천 영역을 숨기면 우측 레일에는 로그인/사용자 패널만 원위치·원형 그대로 유지
- 우측 프로필의 즐겨찾기·스크랩·알림 레이어가 카드 밖에서도 잘리지 않게 표시
- 전체글·개념글·공지, 페이지 수, 글쓰기를 하나의 정렬된 작업바로 표시
- 통신사 IP 차단, 유동 IP의 ISP 표기(SKB/KT/LGU/SKT/딜라이브/세종/헬로, BGP 기반)와 해외 IP 국가 추정 표기(일본·미국 등), 국내·모바일·해외/프록시 배지
- 디시 자체 차단글, 사용자, 키워드 숨김
- 제목에 커서 또는 키보드 초점을 맞추면 사진 미리보기(기본 3장, 최대 4장); 이미지 숨김 설정과 자동 자짤 차단을 반영
- 디시 자동 자짤 표식(`#zzbang_div`, `#auto_zzal_img`, `data-azno`)은 즉시 숨기고, 나머지는 `자짤 차단` 버튼의 128-bit 시각 지문으로 판정
- 목록 작성자 클릭·닉네임 옆 `활동` 버튼 또는 본문의 `작성자 분석` 버튼으로 최근 글 목록 표시
- 분석창 Esc 닫기·초점 복원, 요청 취소·시간 제한, 실제 조회한 페이지 수와 표시 글 기준 합계
- 닉네임 옆 닉콘 클릭은 가로채지 않고 원래대로 갤로그 새 탭으로 이동
- 고정·비고정 ID는 UID, 유동은 닉네임과 IP를 함께 대조해 작성자 구분
- 최근 글의 조회·좋아요·댓글과 `댓글 ÷ 좋아요` 비율 집계(좋아요·댓글이 모두 0인 글은 목록 배지 생략)

## 설치

1. [GitHub Releases](https://github.com/fueenai/DCFilter/releases)의 **Assets**에서 `DCFilter-버전.zip`을 받습니다. 자동 생성되는 `Source code (zip)` 대신 배포용 ZIP을 선택하세요.
2. 계속 사용할 위치에 압축을 풉니다. 설치 후에도 이 폴더를 이동하거나 삭제하지 마세요.
3. Chrome에서 `chrome://extensions`, Edge에서 `edge://extensions`를 열고 `개발자 모드`를 켭니다.
4. `압축해제된 확장 프로그램을 로드합니다`를 누르고, 압축을 푼 폴더 중 `manifest.json`이 바로 들어 있는 폴더를 선택합니다.
5. 디시인사이드 갤러리 탭을 새로고침합니다. 확장 아이콘을 누르면 기능별 설정을 바꿀 수 있습니다.

로컬 AI 모델이 포함되어 ZIP 용량과 압축을 푼 폴더 크기가 일반적인 확장보다 큽니다. 별도 API 키나 모델 다운로드 없이 사용할 수 있습니다.

## 수동 업데이트

이 방식으로 설치한 확장은 GitHub의 새 버전으로 자동 업데이트되지 않습니다.

1. [최신 Release](https://github.com/fueenai/DCFilter/releases)의 변경 사항을 확인하고 새 `DCFilter-버전.zip`을 받습니다.
2. 필요하면 설정 화면에서 JSON 백업을 내보냅니다. 이 백업에는 읽음 기록과 자짤 이미지 지문이 포함되지 않습니다.
3. 새 ZIP의 내용을 **기존 설치 폴더와 같은 경로**에 덮어씁니다.
4. 확장 관리 화면에서 DCFilter의 새로고침 버튼을 누른 뒤, 열려 있는 디시인사이드 탭도 새로고침합니다.

기존 확장을 제거하거나 다른 경로에서 새로 등록하면 기존 설정·로컬 기록이 이어지지 않을 수 있습니다.

## 키보드

- `J`: 다음 일반 게시글
- `K`: 이전 일반 게시글
- `Enter`: 선택한 글 열기
- `G`: 첫 글
- `Shift+G`: 마지막 글
- `Esc`: 선택/미리보기 닫기
- 작성자 `활동` 버튼: Tab으로 이동해 Enter/Space로 열기. 분석창에서 Tab 순환, Esc 닫기
- 설정창 `Ctrl+S`: 저장. 검색 중 `Esc`: 검색 지우기

## 데이터와 한계

- 설정 → **차단**의 ‘AI 봇 의심 댓글 접기’가 기본으로 켜집니다. ‘거르고 싶은 봇 댓글 예시’에 기본 예시가 등록되어 있으며 추가·삭제할 수 있습니다. ‘뚜렷한 패턴만’이 기본이고 ‘더 넓게 접기’는 정형 표현 조합에 더 민감합니다.
- 댓글 필터는 **문장 패턴과 등록 예시를 비교하는 규칙 기반 추정**입니다. AI 작성자를 인증하거나 생성 여부를 판별하는 모델이 아닙니다. 짧은 맞장구 한 문장만으로 사람과 봇을 구분할 수 없으며 오탐·누락이 가능합니다. 예시 전체와 유사한 댓글은 접지만 ‘AI’, ‘목소리 복제’, ‘자동화’ 같은 주제 단어만으로 접지는 않습니다.
- 댓글 본문만 접으므로 작성자·시간·신고/답글 기능과 다른 대댓글은 유지됩니다. ‘댓글 보기’로 펼치고 다시 접을 수 있습니다. 본문이 바뀌거나 댓글 DOM이 새로 로드되면 다시 판정합니다. 필터를 끄면 원문을 복원합니다.
- 댓글 내용과 판정은 현재 페이지에서만 처리하며 외부 전송이나 추가 모델 다운로드가 없습니다. 직접 등록한 예시는 기존 설정처럼 브라우저 설정 동기화 및 JSON 백업에 포함됩니다.
- 이미지 보호는 기본으로 켜집니다. 설정 → **이미지**에서 ‘혐짤 AI 사전 차단’, ‘성적 이미지도 차단’, 엄격/보통 기준을 변경합니다. **0.6.2부터 검사를 끝냈지만 판별이 애매한 정지 이미지는 기본으로 표시**합니다. ‘판별이 애매한 이미지도 가리기’를 켜면 계속 가립니다. 검사 중·실패·지원하지 않는 형식과 유해 의심 판정은 이 옵션과 관계없이 계속 가리며 본문의 ‘이번만 보기’/‘다시 가리기’로 직접 조절합니다. 애매한 이미지 표시는 안전 판정을 뜻하지 않으며 유해 이미지가 더 노출될 수 있습니다.
- AI 모델과 실행 파일 약 96MiB가 확장에 포함됩니다. API 키·별도 요금·모델 서버 연결 없이 PC의 CPU에서 검사하며, 원본 이미지 다운로드는 디시 서버에만 요청합니다. 모델을 처음 읽을 때는 시간이 걸리고 탭마다 메모리를 사용합니다.
- 이 기능은 CLIP의 이미지·문장 유사도를 이용한 **실험적 분류**입니다. 검증된 혐짤 전용 탐지기가 아니며, 통과 판정도 안전 보장은 아닙니다. 동물·만화·게임·음식 등을 잘못 가리거나 유해 이미지를 놓칠 수 있습니다. 본문 이미지를 모두 막으려면 기존 ‘이미지 숨기기’를 사용하세요.
- GIF·움직이는 WebP/APNG·영상·외부 임베드는 자동으로 공개하지 않습니다. 반응형 이미지와 검사 불가 형식도 가려둘 수 있습니다. 사이트의 CSS 배경 이미지·새 창의 원본 이미지·모바일 디시·별도 갤로그는 검사 대상이 아닙니다.
- AI 판정 캐시는 현재 탭의 메모리에만 보관합니다. 확장이 이미지 원본이나 판정 기록을 별도 기록·동기화하지는 않지만, 원본 다운로드에는 브라우저의 일반 캐시가 사용될 수 있습니다. 모델 출처·라이선스는 [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md), 배포 파일 해시는 `models/clip-vit-base-patch32/asset-integrity.json`에서 확인할 수 있습니다.
- 읽음 기록은 브라우저 로컬에만 최대 3,000개, 30일간 보관합니다. 시크릿 창과 미리보기는 기록하지 않으며, 설정에서 읽음 표시를 끄거나 기록을 비울 수 있습니다.
- 댓글 증가분은 현재 목록에 표시된 개수와 마지막 열람 시 개수의 차이입니다. 별도 서버 조회는 없고, 삭제된 댓글이 있으면 실제 새 댓글 수와 다를 수 있습니다.
- 목록 위치는 탭별로 최대 20개, 12시간 보관합니다. 같은 갤러리라도 페이지·검색 조건이 다른 목록은 구분하며, 복원 중 직접 스크롤하면 자동 이동을 중단합니다.
- 작성자 분석은 현재 갤러리의 검색 결과만 집계합니다. 검색 페이지 수와 최대 글 수는 설정에서 바꿀 수 있습니다.
- 유동 작성자는 닉네임뿐 아니라 DC가 노출한 축약 IP까지 일치하는 글만 포함합니다.
- 국내 IP 표시는 2026-07-23 APNIC KR IPv4 할당을 /16 단위로 압축한 로컬 데이터입니다.
- 통신사 표시는 DC에서 흔히 보이는 공개 모바일 대역 기반 추정입니다. VPN/프록시는 완전하게 판별할 수 없습니다.
- 미리보기와 작성자 분석은 사용자가 해당 기능을 실행할 때 디시인사이드 페이지를 직접 요청하며, 외부 분석 서버로 데이터를 보내지 않습니다.
- 자동 갱신·분석·미리보기 요청은 문서별 분당 최대 12회로 제한합니다. 여러 탭의 요청량을 합산하는 제한은 아닙니다.
- 이미지 지문으로 수동 등록한 차단은 본문 이미지에 적용됩니다. 미리보기에서는 디시 자동 자짤 표식만 제외합니다.
- JSON 백업에는 저장된 기능 설정, 키워드·사용자 차단 목록, 등록한 댓글 예시가 포함됩니다. 읽음 기록과 자짤 지문은 로컬에 유지되며 JSON 백업에는 포함되지 않습니다.
- 고정닉은 UID로, 유동은 닉네임+축약 IP로 대조합니다. 축약 IP가 같아도 다른 사람일 수 있습니다.

## 개인정보와 네트워크

- 이미지 AI 검사와 댓글 판정은 브라우저 안에서 실행합니다. 이미지 픽셀·댓글 본문·판정 결과를 AI 제공업체나 별도 분석 서버로 전송하지 않으며, API 요금도 발생하지 않습니다.
- 기능 설정, 키워드·사용자 차단 목록, 직접 등록한 댓글 예시는 **브라우저 동기화 저장소**에 저장합니다. Chrome·Edge의 계정 및 동기화 설정에 따라 브라우저 제공업체를 통해 다른 기기로 동기화될 수 있습니다. 로컬 AI 검사라는 설명이 모든 설정의 외부 동기화까지 없다는 뜻은 아닙니다.
- 읽음 기록과 수동 등록한 자짤 지문은 확장의 로컬 저장소에 보관합니다. 목록 복귀 위치는 탭의 세션 저장소를, 화면 테마 초기 적용은 브라우저의 로컬 캐시를 사용합니다.
- 목록 갱신·미리보기·작성자 분석은 디시인사이드 페이지를 요청하고, 이미지 검사는 허용된 디시인사이드 이미지 서버에서 원본을 읽습니다. 이때 해당 서버에는 일반적인 웹 요청이 전달됩니다. 목록 자동 갱신은 현재 로그인 상태를 사용합니다.

## 개발·검증

소스 저장소에서 `node scripts/check.cjs`로 구문, manifest 파일 참조, 설정창 ID, 모델·실행 파일 해시와 자동 테스트를 확인합니다.

`powershell -NoProfile -ExecutionPolicy Bypass -File scripts/package.ps1`은 검사 후 허용 목록의 확장 파일·로컬 AI 모델·라이선스만 ZIP으로 만들고 압축 내부 해시를 원본과 비교합니다. 실행 정책 예외는 이 명령의 프로세스에만 적용하며 시스템 정책을 변경하지 않습니다. 같은 버전의 기존 ZIP은 덮어쓰지 않습니다. 테스트 프로필·캐시·스크린샷은 배포하지 않습니다.

개발용 스크립트와 테스트는 소스 저장소에 있으며, 설치용 ZIP에는 실행에 필요한 파일만 포함됩니다. 자동 테스트 통과는 AI 판별 정확도나 모든 갤러리 화면의 호환성을 보장하지 않습니다.

## 라이선스

DCFilter 자체 코드에는 별도의 오픈소스 라이선스를 아직 지정하지 않았습니다. 포함된 모델·라이브러리에는 각각의 라이선스가 적용되며, [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md)와 해당 구성 요소의 라이선스 파일에서 확인할 수 있습니다.
